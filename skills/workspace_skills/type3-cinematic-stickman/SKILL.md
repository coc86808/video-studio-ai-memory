## 1. Visual DNA & Rules

1. **Theatrical Stage & Lighting:**
   - Every scene exists on an obsidian slate stage (`#0C1014`) illuminated by an overhead conical spotlight beam (`spotlight-beam`).
   - The stage floor features an active horizontal contact beam (`stage-floor`) and soft golden floor reflection (`stage-reflection`).
2. **Actor Language:**
   - Minimalist vector stick figures (`stickActor()`) with bold white strokes (`stroke-width="9"`), glowing circular heads, and grounded contact shadows (`<ellipse rx="40" ry="9" .../>`).
   - Signature props glow in antique gold (`#E5B842`), such as the briefcase labeled "SKILL", the ledger book, or the quill.
3. **3D Mechanical Widgets:**
   - Instead of static images, illustrate concepts with dynamic mechanical graphics:
     - **Balance Scale:** Pivoting seesaw beam balancing Debit (+Green) vs Credit (-Gold).
     - **Time Odometer:** Rolling number ticker rewinding through centuries.
     - **Clean Ledger Sheet:** Structured transaction rows with animated checkmarks.
     - **Profit Counter:** Dynamic counting up from 0 to target value with surge graph.
4. **Kinetic Captions:**
   - Placed at `top: 1420px` in a rounded dark badge with a gold border.
   - Synchronized word-by-word with Bengali font `Hind Siliguri`.
   - Chunked into 2–3 words max in vertical 9:16 to prevent platform UI clipping.
5. **Procedural DSP Sound:**
   - Pure algorithmic audio synthesis via `tools/sfx.py`: whooshes on entrances, pops on badges, dings on insights, and booms on problem impacts.

## 3. End-to-End Production Workflow

### Step 1: Scaffold Project
```bash
# 1. Create project directories
mkdir "projects/<name>/assets"

# 2. Copy starter index.html
cp "template/index.html" "projects/<name>/index.html"

# 3. Copy voiceover
cp "<path_to_voiceover>.mp3" "projects/<name>/assets/voice.mp3"
```

### Step 2: Configure & Generate Timestamps
Write `config.json`:
```json
{
  "width": 1080,
  "height": 1920,
  "fps": 30,
  "duration": 62.75
}
```
Run `words_to_js.py`:
```bash
python tools/words_to_js.py "<path_to_words.json>" "projects/<name>"
```

### Step 3: Configure Theme (`theme.css`)
Ensure `theme.css` has the Type 3 spotlight and color definitions:
```css
@font-face { font-family: BrandFont; src: url(../../fonts/HindSiliguri-Bold.ttf); font-weight: 700; }
:root {
  --bg: #0C1014;
  --highlight: #E5B842;
  --gold: #FFD255;
  --success: #32D74B;
  --danger: #FF453A;
  --info: #0A84FF;
  --font: BrandFont, 'Hind Siliguri', sans-serif;
}
```

### Step 4: Author `scenes.js`
Use the pre-built actor and widget recipes from:
- `references/actor_recipes.js`
- `references/widget_recipes.js`

### Step 5: Visual Verification Stills
Before doing a full render, capture stills at key visual moments:
```bash
node tools/render.js projects/<name> still 2.0,8.0,17.0,25.0,35.0,45.0,55.0
```
Inspect the images with `read_file` to verify text contrast, margins, and stickman grounding.

### Step 6: Master Build
```bash
python tools/build.py projects/<name> --music "<path_to_bgm>.wav" --music-db -24 --sfx-db -12 --parts 2
```
Output: `output/<name>_final.mp4`

## 4. Fast Incremental Scene Fixes (`--fix`)

When making adjustments to a specific scene (e.g. tuning a text string, fixing a stickman arm, or retiming an animation):
1. Edit only the target scene in `scenes.js`.
2. Run `--fix` with the scene's exact time slice:
```bash
python tools/build.py projects/<name> --fix <start_sec>-<end_sec>
```
The engine renders **only those frames** in ~15 seconds and splices them losslessly into a new version `output/<name>_final_v2.mp4` without re-rendering the rest of the video!

## 5. Continuous Improvement Invariants

When authoring or polishing Type 3 scenes:
- **Foot Anchoring:** Always include the `<ellipse cx="90" cy="245" rx="40" ry="9" fill="rgba(0,0,0,0.55)"/>` contact shadow so stick figures feel grounded on the floor.
- **Vertical Spacing Hierarchy:** 
  - Top 15% (`0 - 280px`): Category badge / Scene pill / Header.
  - Center 55% (`280px - 1350px`): Main hero visual (Actor + 3D Card / Mechanical widget).
  - Stage Floor (`1350px - 1420px`): Horizontal beam and character feet contact.
  - Bottom 30% (`1420px - 1920px`): Caption pill badge and safe buffer for mobile platform icons.
- **Micro-Camera Dynamics:** Always set `{ push: 1.04 }` or `{ push: 1.05 }` on `scene()` calls so the camera gently drifts forward during dialogue, eliminating static feel.
- **Punch Timing:** Pair camera punches (`punch(t)`) and shakes (`shake(t)`) with significant impact words or sudden revelations.
